## 开源项目

### Reason Network：让团队里的 coding agents 互相找到彼此

![Reason Network 官方仓库预览](https://opengraph.githubassets.com/1/reason-machines/reason-network)

仓库描述为“your team's coding agents, talking to each other”，采用每台电脑一个 daemon 的点对点架构；README 明确列出 Codex、Claude Code、Cursor、Gemini CLI、Copilot CLI 等会话的发现与消息能力。项目于 10 月 16 日创建，核验时 GitHub 显示 160 stars、Apache-2.0 许可证。它值得关注，是因为 Agent 协作的最小基础设施已经从提示词编排延伸到在线状态、消息抵达和跨机器连接。

来源：[官方仓库](https://github.com/reason-machines/reason-network) · [GitHub API 元数据](https://api.github.com/repos/reason-machines/reason-network) · [官方 README](https://raw.githubusercontent.com/reason-machines/reason-network/main/README.md)

### Co-op Anything：把长任务 Agent 变成可测试的游戏改造流水线

![Co-op Anything 官方仓库预览](https://opengraph.githubassets.com/1/cranebeaker/coop-anything)

项目 README 要求用户把目标游戏交给 coding agent，由 Agent 研究现有 mod、逆向引擎、修复或从零构建联机，再用游戏内 bot 测试并打包给朋友安装。10 月 17 日的官方提交新增 Mega Man X 与 X4 的重编译协作目录；仓库核验时显示 97 stars，MIT 许可证。它的价值不在某一款游戏，而在于把“Agent 能否完成复杂交付”拆成可复用 playbook、工具和自动化 QA。

来源：[官方仓库](https://github.com/cranebeaker/coop-anything) · [10 月 17 日提交](https://github.com/cranebeaker/coop-anything/commit/87f35aa6e4559773447bd7064319fd5f54cf0b0c) · [GitHub API 元数据](https://api.github.com/repos/cranebeaker/coop-anything)

### TokenForge：面向 coding agent 的上下文优化层

![TokenForge 官方仓库预览](https://opengraph.githubassets.com/1/speedydivid/TokenForge)

TokenForge 于 10 月 17 日创建，README 声称通过 hooks 和 MCP 拦截工具输出，用 SQLite/FTS5 保存会话知识，并面向 Claude Code、Gemini CLI、VS Code Copilot、OpenCode 和 Codex CLI 提供路由。仓库暂未声明许可证，且“最多减少 98%”是项目方自述，尚未见独立基准；因此应把它当作待验证的工程尝试，而不是已证实的性能结论。

来源：[官方仓库](https://github.com/speedydivid/TokenForge) · [官方 README](https://raw.githubusercontent.com/speedydivid/TokenForge/main/README.md) · [创建后的首批提交](https://github.com/speedydivid/TokenForge/commit/da81bd42ee4fdf8d238b559ab574ecd2d5c12db)

## 业界动态

Reason Network 在 10 月 17 日发布 [v0.10.5](https://github.com/reason-machines/reason-network/releases/tag/v0.10.5)。官方变更说明包含：让托管引擎服务运行实际设置它的 Reason CLI，以及转义 systemd 值、处理空 CLI 路径。这是偏基础设施的修复，但它说明 Agent 协作产品的竞争点也在后台服务的可运维性，而不只是前端对话体验。

## 趋势 / 编辑简评

今天的共同主题是 **“把 Agent 变成可编排、可观察、可恢复的系统”**。Reason Network 处理 Agent 之间的网络与身份，Co-op Anything 处理长任务的工具链与 QA，TokenForge 处理上下文和记忆。三者都把模型之外的运行时当成一等公民。需要保持克制的是：TokenForge 的节省比例仍是未经独立验证的项目方声明；同样，GitHub stars 只能说明公开关注度，不能替代可靠性、许可证审查或生产基准。
